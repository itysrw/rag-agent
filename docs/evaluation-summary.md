# RAG 评测摘要

## 真实历史基线 · 2026-11-08

六份 Ready.gov 英文 PDF（`day17-v1`），50 道中文单轮题（`day17-v1.1`），含 40 道有答案题和 10 道无答案题。模型为 `deepseek-v4-flash`，评分规则为 `day18-rubric-v1`，当次发起 65 次模型请求。

| 指标 | 结果 | 判定口径 |
| --- | ---: | --- |
| 正常返回 | 50/50 | 单轮执行正常结束 |
| 整体规则通过 | 11/50 | 有答案题按答案规则通过（不要求引用全命中），加上无答案题的正确拒答 |
| 候选来源全命中 | 30/40 | 同轮重排前 5 个片段覆盖全部标注来源页 |
| 最终引用全命中 | 6/40 | 输出引用覆盖全部标注文档与物理页码 |
| 答案与引用联合通过 | 3/40 | 知识检索回答覆盖所有固定事实组，且引用全命中 |
| 正确拒答 | 8/10 | 符合无答案题的拒答规则 |

有答案题中有 29/40 触发固定拒答。规则按固定事实组自动评分，部分表述需要人工抽查。单轮图执行的首题用时 97.50 秒，后续 49 题 P50 为 6.82 秒、P95 为 8.39 秒。该计时覆盖工具选择、检索、重排及生成，HTTP 与会话落库位于计时窗口外。 [历史发布摘要](https://github.com/itysrw/rag-agent/blob/3917865e69c46bda5a4d1cc23de105d88006f91b/README.md#day18-真实评测基线) · [冻结数据与评分口径](../eval/README.md#day18-单轮评测)

## 生成前证据覆盖 · 2026-11-18

同一批 50 题，以离线候选和重排分数对照三种证据筛选规则。分母 40 为有答案题，命中要求进入生成上下文的片段覆盖**全部**标注来源页。此次回放调用生成模型 **0 次**。

| 证据选择 | 有答案题全页覆盖 | 有上下文的无答案题 |
| --- | ---: | ---: |
| 前 5 名按向量分数筛选 | 6/40 | 2/10 |
| 前 5 名加入重排分数门槛 | 20/40 | 2/10 |
| 从完整重排名单补齐来源页 | 31/40 | 2/10 |

两道放行的无答案题使用相同片段。规则在本题集上选定，新规则的全量真实回答、最终引用、拒答与新语料泛化仍待评估。 [证据筛选与回放记录](day19-evidence-gate.md)

## 历史检索排名对照 · 2026-10-27 至 2026-10-28

10 月 27 日对照向量、BM25 和 Hybrid，10 月 28 日复用同组题对照 Rerank。两次使用同一份自撰企业手册、24 个片段、12 道正样本以及 3 道库外负样本。Hit@1/5 表示前 1/5 项含短语标注目标的题目比例，MRR@5 对首个命中位置取倒数后按 12 题平均，前 5 项未命中计零。

| 方法 | Hit@1 | Hit@5 | MRR@5 |
| --- | ---: | ---: | ---: |
| 纯向量 | 9/12 | 11/12 | 0.812 |
| BM25 | 10/12 | 12/12 | 0.882 |
| Hybrid | 11/12 | 12/12 | 0.944 |
| Hybrid + Rerank | 11/12 | 12/12 | 0.958 |

Hybrid 补回 1 道纯向量前 5 项漏掉的题。重排将一题的第一个相关片段从第 3 升至第 2。Hybrid 对 3 道负样本均返回候选，生成前的证据筛选在其后执行。这组指标用于说明小样本上的排序表现。 [三路检索实验](day11-hybrid-comparison.md) · [重排实验及逐题名次](day12-rerank-comparison.md)
