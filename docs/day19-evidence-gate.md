# Day19 证据过滤对照

2026-11-18 在同一批 50 道冻结题上对比证据过滤规则。使用六份原版英文 PDF，按 `o200k_base` 的 300/60 切分。用本机缓存的 BGE 向量模型做精确余弦检索，复用 BM25、RRF 和 BGE 重排，固定每题的重排前五个候选，再分别执行两套过滤规则。实验没有调用生成模型，共 0 次付费请求。

| 指标 | 原规则：向量 ≥ 0.46 | 新规则：向量 ≥ 0.46 或重排 ≥ −2.0 |
|---|---:|---:|
| 上下文包含全部标注来源页 | 6/40（15%） | 20/40（50%） |
| 有答案却没有任何上下文 | 27/40 | 10/40 |
| 有上下文的无答案题 | 2/10 | 2/10 |
| 50 题送给生成阶段的片段总数 | 40 | 90 |

未过滤的候选中有 30/40 题包含全部标注来源页。作为对照，只把向量门槛降到 0.42 时，来源页全命中为 12/40，有上下文的无答案题为 3/10。因此默认启用重排门槛 −2.0。这个值是固定版本 BGE 重排模型的原始输出分数，选自本题集的离线对照。页级覆盖衡量送给模型的证据范围，真实回答的正确率和拒答结果仍需生成评测。更多题会进入生成阶段，实际使用中的模型请求和上下文量可能增加。

## 扩展来源页覆盖

在同一语料和同一批 50 题上保存了完整重排名单。混合检索交给重排的 20 个片段覆盖了 40/40 题的全部标注来源页。只看重排前五名时，覆盖降为 30/40。两次筛选使用相同的候选分数，分别执行上一版和当前代码。

| 指标 | 前五名内筛选 | 从完整排名补页 |
|---|---:|---:|
| 上下文包含全部标注来源页 | 20/40（50%） | 31/40（77.5%） |
| 有答案却没有任何上下文 | 10/40 | 7/40 |
| 有上下文的无答案题 | 2/10 | 2/10 |
| 50 题的上下文片段总数 | 90 | 113 |

原有 20 道全命中题全部保留，新增 11 道，跨段题从 3/12 提升至 9/12，多跳题从 3/10 提升至 7/10。两道有上下文的无答案题在两版中使用了相同的片段。

默认先从前五名选取向量分数至少 0.46 或重排原始分数至少 −2.0 的片段。若没有入选片段，允许同一片段的两项分数同时达到 0.40 和 −3.0。只要入选片段中有一项重排分数达到 −3.0，便可复用完整名单中达到主门槛的其他页，也可补入向量分数达到 0.40 的同文档邻页。优先保留不同页，空位可留给同页片段，每题最多 5 个片段。

规则根据这批题选择。数据衡量生成前的页覆盖和证据放行情况。模型生成答案后的准确率、引用表现和拒答率仍待验证。本轮使用 300/60 的 o200k 分块，共 0 次付费请求。Day19 历史上的 500/100（BGE token）与 200/40（o200k）在完整 RAG 对照中同为 7/40。

当前规则用于 `/chat` 的 JSON、SSE 和评测入口。将 `RAG_MIN_RERANKER_SCORE` 设为 `disabled` 可恢复前五名内只按向量分数筛选。管理员 trace 记录同次重排名单及每个片段的 `vector_score`、`reranker_score` 和 `included_in_context`。
